# ساختار ماژولار اپ دانیا

## فایل‌ها
- `app.html` نقطه ورود اصلی برنامه است.
- `assets/css/app.css` شامل استایل‌های استخراج‌شده از فایل اصلی است.
- `assets/js/app.js` شامل منطق برنامه و امکانات فعلی است.
- `assets/favicon.png` و `assets/apple-touch-icon.png` آیکون‌های تب مرورگر و موبایل هستند.
- `pages/` شامل صفحات ورود مستقیم به هر بخش است. هر صفحه، اپ اصلی را با تب مناسب باز می‌کند تا ورود کاربر، وضعیت Supabase، داده‌ها و رفتارهای فعلی تکراری یا از هم جدا نشوند.

## مسیرها
ساختار پوشه‌ها را دقیقاً حفظ کنید. فایل `app.html` باید کنار پوشه‌های `assets` و `pages` باشد.
در GitHub Pages، صفحه‌های هر بخش از مسیرهایی مانند `pages/game-maker.html` قابل دسترسی‌اند و به `../app.html?tab=game-maker` هدایت می‌شوند.

## بخش‌های موجود
- `pages/dashboard.html`
- `pages/private.html`
- `pages/classes.html`
- `pages/settings.html`
- `pages/certificate.html`
- `pages/exam.html`
- `pages/whiteboard.html`
- `pages/game-maker.html`

## نکته مهم
نسخه اصلی یک برنامه تک‌صفحه‌ای (SPA) است؛ محتوای بخش‌ها در زمان اجرا توسط JavaScript ساخته می‌شود. بنابراین صفحات داخل `pages/` ورودی‌های مستقل به تب‌ها هستند، نه کپی جداگانه‌ای از منطق هر قابلیت. این روش از تکرار منطق احراز هویت و اتصال Supabase جلوگیری می‌کند و نگهداری را ساده‌تر می‌سازد. برای تبدیل واقعی هر قابلیت به یک ماژول HTML/JS مستقل، لازم است وابستگی‌های توابع و وضعیت مشترک هر بخش به‌صورت مرحله‌ای بازطراحی شوند.


به‌روزرسانی سایدبار: گروه‌های کلاس‌ها، خدمات آموزشی و حساب کاربری به زیرمنوهای باز و بسته‌شونده تبدیل شده‌اند. گزینه «تخته هوشمند» نیز اضافه شده است. صفحه فعلی تخته هوشمند یک صفحه معرفی/جایگاه توسعه است؛ مدل‌های سه‌بعدی هنوز پیاده‌سازی نشده‌اند.
